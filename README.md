# EditLedger for HarmonyOS PC

文稿编辑、语法着色、查找替换与编码格式保存。

此仓库保存当前鸿蒙 PC 应用源码、构建配置、测试与开源许可材料。开发者中心版本已提交审核，审核状态以开发者中心为准。

源码来自 [EditLedger 的 AtomGit 工程](https://atomgit.com/2301_80739235/editledger-notepadqq-adaptation)，固定提交 `d89d63dcfb49e25bf9c40afdb3d9588eec9145e7`。本次以当前源码快照建立 GitHub 历史，详情见 SOURCE-SNAPSHOT.json；源码说明、组件版权和对应源码材料保留在仓库中。

构建时使用自己的 SDK、运行时依赖与本机签名材料。按仓库中各组件的原有许可使用、修改和再分发。
